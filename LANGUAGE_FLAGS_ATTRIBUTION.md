# Language selector flags

`language-flags.png` was rendered from flag emoji glyphs in Google's Noto Color
Emoji font (`NotoColorEmoji.ttf`). The font is distributed under the SIL Open
Font License 1.1. The sheet is a raster rendering of those glyphs, not a copy
of the font. Source: https://github.com/googlefonts/noto-emoji

The flags serve only as compact visual cues for language choices. The full
native language names remain visible in the selector.

The interface also bundles `fonts/NotoSansCJK-Regular.ttc` (Noto Sans CJK, SIL
Open Font License 1.1) and `fonts/IBMPlexSansDevanagari-Regular.ttf` (IBM Plex Sans Devanagari, SIL Open
Font License 1.1). License/copyright notices are in `fonts/NOTO_LICENSE.txt`
and `fonts/IBM_PLEX_LICENSE.txt`.
